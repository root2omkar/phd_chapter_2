#ReadMe

The `flavi_cov_results` contains the results from FLAVi-CoV annotator for CLUSTAL OMEGA v1.2.4, MUSCLE v5, and MAFFT v5.2.5woe gene annotated alignments, including outgroup and ingroup

`clustal_g_o` folder contains files for CLUSTAL OMEGA v1.2.4 gene annotated alignment created with FLAVi-CoV.

`mafft_g_o` folder contains files for MAFFT v5.2.5woe gene annotated alignment created with FLAVi-CoV.

`muscle_g_o` folder contains files for MUSCLE v5 gene annotated alignment created with FLAVi-CoV.
