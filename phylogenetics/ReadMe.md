```iqtree_results``` folder contains iqtree3 results for all the alignments.

The results are organized in the same way as the ```alignments``` directory and include both alignments and IQTree3 results.

The ```.treefile``` in every IQTree3 result is used to create the phylogenetic tree.

```trees``` folder contains the phylogenetic trees in pdf format.

All the trees were created using ITOL (Interactive Tree Of Life) online tool, which is a tool for the display, annotation, and management of phylogenetic and other trees. You can click ```https://itol.embl.de/``` to access this tool.

##IQTREE3 Commands

Below are the commands used for creating IQTREE3 results

Alignments with gene annotation have the nexus partition file which was used for creating the tree results.

### With annotation - Partition File

#### For alignments with Outgroup

```

iqtree3 \
  -s clustal_g_o.fasta \
  -p partition.nexus \ 
  -m MFP \
  -B 1000 -bb 1000 -alrt 1000 \
  -o DQ022305_,DQ084199_,GQ153539_,GQ153540_,GQ153541_,GQ153542_,GQ153543_,GQ153544_,GQ153545_,GQ153546_,GQ153547_,GQ153548_,KY352407_,MG772933_,MG772934_,MT040333_,MT040334_,MT040335_,MT040336_,MT072864_,NC025217_ \
  -T 8 \
  --rate --mlrate \
  -seed 50 \
  --prefix clustal_g_o
  

```


#### For alignments with Ingroup-only

To generate the results, an ingroup-only alignment was performed, and the reference genome Wuhan-HU-1 ```MN908947_``` was used as an outgroup.

```

iqtree3 \
  -s clustal_g_i.fasta \
  -p partition.nexus \ 
  -m MFP \
  -B 1000 -bb 1000 -alrt 1000 \
  -o MN908947_ \
  -T 8 \
  --rate --mlrate \
  -seed 50 \
  --prefix clustal_g_i
  
```

### Without annotation - No partition file  

Alignments with no gene annotation do not have the nexus partition file.
